# コミットプレフィックス一覧

## プレフィックス一覧と使用例

| プレフィックス | 意味 | 使う場面 |
| -------------- | ------ | --------- |
| `ADD` | 新規追加 | 新機能・新ファイル・新ドキュメント |
| `FIX` | バグ修正 | 誤動作・クラッシュ・誤表示の修正 |
| `UPDATE` | 既存の改善・更新 | 動作している機能の変更・強化 |
| `REMOVE` | 削除 | 不要コード・ファイルの除去 |
| `REFACTOR` | リファクタリング | 動作変えずに構造改善 |
| `DOCS` | ドキュメントのみ | `.md` 編集、コメント追加 |
| `CHORE` | 雑務 | 依存更新、設定変更、ビルドスクリプト |
| `PERF` | 性能改善 | 速度・メモリ最適化 |
| `TEST` | テスト | テスト追加・修正 |
